Run Club App

A simple application designed to streamline operations for our run club.

Current Features

This application is currently in development. The primary focus right now is on managing attendance:

Taking Attendance: Quickly and easily record who is present at runs or events.

Tracking Attendance: Maintain a history of attendance over time.

Efficient Record Usage: Make attendance data more accessible and useful for club operations.

Future Development

More features are planned and will be added as development continues. Stay tuned!
